# Pilot Onboarding Pack

## Objective
Prepare the first beta businesses in the MVP target segment: independent Italian restaurants and trattorie.

## Pilot cohort
- 2–3 single-site restaurant or trattoria businesses
- 1 admin/owner per business
- 2 staff users per business
- 1 optional auditor/consultant user when read-only review is required

## Onboarding path
1. Use the public bootstrap flow once to create the organization and first admin.
2. Sign in as the admin and complete the organization profile.
3. Add the primary location.
4. Create the staff users from Settings.
5. Configure presets for temperature, cleaning, receiving, and checklist tasks.
6. Configure reminder rules for opening and closing routines.
7. Generate the day’s tasks and confirm they appear on the dashboard.
8. Upload the starting compliance documents:
   - HACCP manual
   - Permit
   - Certificate
   - Procedure
   - Store layout

## Pilot success path
- Staff can complete temperature, cleaning, receiving, incident, and checklist activity
- Overrides always require a reason
- Admin can export CSV and PDF reports
- Admin can review documents and audit history without engineering help

## Feedback to collect every week
- Missing fields in daily workflows
- Confusing steps in onboarding or task completion
- Reporting gaps for inspections
- Reminder timing or duplication problems
- Performance issues on dashboard, exports, or document transfer

## Go / no-go for wider beta
- Go when staging validation passes, pilot users complete daily workflows unaided, and report outputs are inspection-ready
- No-go when auth, authorization, reporting, storage, or performance issues block normal daily use
